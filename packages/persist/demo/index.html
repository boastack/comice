@comice/persist — manual SPA handoff demo

A real SPA is simulated here by two "route" <div>s in the SAME document — clicking a thumbnail hides the listing route and shows the detail route, exactly the DOM-patching an SPA router does. persist() is called on both routes' own <img> elements with a matching `match` key; watch the thumbnail's real, literal DOM node grow into the detail hero — not a copy, the same element.
